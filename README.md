# E-Commerce Clone

A responsive front-end e-commerce web application built using HTML, CSS, and Vanilla JavaScript.

## Features

- **Product Listing:** View a grid of products with images, titles, ratings, and prices.
- **Search Functionality:** Filter products dynamically using the search bar.
- **Shopping Cart:** Add items to the cart, update quantities, and view the cart summary.
- **Checkout Page:** Review selected items, calculate order totals, and manage cart contents.
- **Responsive Design:** Optimized for both desktop and mobile devices with a custom hamburger menu for mobile navigation.

## Tech Stack

- **HTML5:** Semantic markup for structure.
- **CSS3:** Vanilla CSS for styling, utilizing Flexbox and CSS Grid for layout.
- **JavaScript (ES6):** Modular JavaScript (`type="module"`) for handling logic, DOM manipulation, and state management.

## Project Structure

- `index.html`: The main landing page displaying the product grid and navigation.
- `checkout.html`: The cart and checkout page.
- `Styles/`: Directory containing all CSS stylesheets (`general.css`, `navbar.css`, `grid.css`, `checkout-grid.css`, etc.).
- `scripts/`: Directory containing JavaScript modules (`navbar.js`, `grid.js`, `checkout.js`).
- `data/`: Directory containing data structures for products and cart (`product.js`, `cart.js`).
- `Logo/`, `Pdt_Img/`, `Stars/`: Directories for images and icons.

## How to Run Locally

1. Clone this repository or download the source code.
2. Open `index.html` in your preferred web browser. Alternatively, you can use a local development server like VS Code's "Live Server" extension for a better experience.
